# Atividade de introdução ao GitHub

1. Cada aluno da turma possui uma "branch" cujo nome corresponde ao nome de usuário de cada um no github.

2. Vocês trabalharão na branch de cada um de vocês.

3. Editem o arquivo "resposta.md" informando o que for pedido nele.
